# Grundl-ggande-Java-programering
Kursen bygger vidare på de grunder i programmering som de studerande fått med sig från tidigare kurserna i utbildningen och introducerar en mer strukturerad utveckling i form av objektorienterad programmering. Början av kursen fokuserar på att göra de studerande förtrogna med hur man programmerar just i Java, genom att återkomma till de begrepp och projekt som de stött på tidigare i utbildningen, fast denna gång utvecklade med just Java. Inom ramen för detta får de studerande använda sig av IDE:er (Integrated Development Environment, utvecklingsmiljö), såsom exempelvis Eclipse, IntelliJ eller NetBeans. 

I kursen introduceras dessutom ett mycket centralt begrepp inom Javautveckling - JVM. JVM står för Java Virtual Machine och är i praktiken den mjukvara/emulator som tillåter Java att köras på i princip vilken plattform som helst. De studerande även stifta bekantskap med JDK - Java Development Kit, ett kit som ger utvecklare flera olika verktyg för att kunna utveckla med Java.
